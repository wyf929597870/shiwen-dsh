# 移动端方案（待实施）

移动端是可独立工作的拾文客户端，不只是电脑的遥控器。本轮仅记录方案，实施范围为 PC 客户端与独立服务。

## 数据与离线记录

手机持有本地资料库。在外面可以记录日记、想法、编辑已下载内容；保存成功立即落到手机。界面区分“已保存到手机”“待同步”“已同步”“同步失败”和“有冲突”。默认保留手机创建的资料，支持选择近期内容、收藏或全部资料离线保存。

手机首次与固定主资料库配对，使用服务身份与授权凭据确认目标；IP 地址不作为资料库身份。回到同一局域网，应用打开且服务可达时自动同步。后台同步的可用性需按移动平台验证，不承诺关屏后始终执行。

同步必须具备稳定记录 ID、修改版本、删除标记、增量游标、重试幂等和中断续传。双端同时修改时保留双方版本，由用户选择或合并；不能静默覆盖。切换主资料库不得自动合并两套数据。

## 独立 AI

- 有互联网、电脑不可达：手机直连自己的模型供应商，使用手机已有资料和移动端工具，讨论结果可立即保存到本地。
- 主服务可达：可选择服务端 Agent，检索完整资料库并调用电脑上的工具。
- 完全无网络：基础记录、编辑和本地检索仍可用；AI 需另行支持设备本地模型，不作为当前已具备能力。

移动端 Agent 的上下文、记忆、工具权限与任务状态需要独立维护。记录来源、作者、执行设备和 AI 整理行为分别保存。远端工具不可用时应明确提示，不虚构已搜索完整资料库。模型凭据使用设备安全存储，不随普通资料同步；对话是否同步由用户选择，资料关联需要可追溯。

## 实施顺序与验收

1. 完成 PC 的本机服务管理和远端连接，保持统一资料 API。
2. 定义服务身份、配对、版本与删除语义、增量同步协议。
3. 实现移动端本地记录与同步：离线创建、断网重试、重复请求、冲突和删除恢复。
4. 实现移动端模型配置、Agent 与本地资料工具；再接入服务端 Agent。
5. 验证真实 Android/iOS 的安全存储、网络切换、休眠恢复、后台限制与大资料库。

当前 PC/Web 共用后端不等于离线同步已经完成。移动端框架、首发平台、传输协议及本地模型支持仍待选择。
