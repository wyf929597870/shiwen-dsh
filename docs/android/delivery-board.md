# Android 交付状态

更新：2026-11-08。本文记录当前 Android 客户端代码覆盖面和验收边界。它取代早期分阶段计划的进度判断；产品要求与协议决策仍见 [Android 架构与实施说明](README.md)、[同步协议](sync-protocol.md) 和 [界面流程](ux-flows.md)。

## 当前状态

Android 客户端已从探针工程发展为本地原生资料库应用。它使用打包在 APK 内的 React/Capacitor 页面、Kotlin 原生桥接和 Room Repository；不把远端网页加载到拥有原生权限的 WebView。已发布 [Android 0.1.0 正式签名安装包](https://github.com/wyf929597870/shiwen-dsh/releases/tag/android-v0.1.0)。已在现用真机完成同签名覆盖升级、旧草稿恢复、素材保存、页面切换和局域网同步验证；没有全部设备、系统版本和长时间后台场景的完整真机结论。

## 不纳入“已完成”的项目

- 公开 APK 使用独立保管的正式签名；已验证现用设备从前版覆盖升级，不能据此推断所有 Android 系统和历史版本都已通过迁移验收。
- 本轮没有使用用户模型密钥发起真实模型请求；模拟会话测试不能代表供应商流式、计费和限流行为。
- Android 完整副本由已配置的协调服务连接；桌面端、普通浏览器和 Android 并未因此全部变成一个可离线对等网。离线对等同步、自动选主及无中心发现仍不支持。
- 当前仅按 Host 已提供的能力开放插件、调度、外部接入与 Profile 接口；任意 DSH Agent 预设、所有 Skills/MCP 插件的手机执行、通用 Typert Remote 和 Creator 工作流不应由菜单入口暗示支持。
- 还需主线核验目标 Android 真机、低存储、进程强停、后台限制、升级迁移及权限对话框。没有这些证据时不写“已真机全回归”。

## 导航和配置归属

底部固定「对话 / 素材 / 创作 / 回顾 / 设置」。模型密钥、服务器节点、存储和维护集中于设置；无模型时仍可直接记录。资料库切换后，草稿、记录和会话都绑定明确 `libraryId`，节点管理操作绑定 `nodeId` 与配置版本。

设置中的插件、自动化任务和外部接入使用当前节点的真实服务能力；不可用能力显示为不可用，不使用无效按钮模拟成功。外部客户端令牌只由 Android 原生安全窗口展示，不进入网页 JavaScript。

## 验收与构建

浏览器预览是 synthetic bridge fixture，只可用于语言、主题、布局和交互层检查。Native Repository、文件选择器、同步、服务器 API、桌面包以及 AI 模型请求必须分别通过对应测试或真实环境检查。

构建/测试命令与签名边界见 [Android 实施说明](README.md#9-测试性能目标和发布)。最新阶段结论由主线在合并或发布前补入本文；本文件不替代 CI、Android instrumentation 或设备验收日志。
