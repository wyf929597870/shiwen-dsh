## 已验证

- Android 界面静态引用检查、调试包构建、Android JVM 单元测试通过；移动端测试 83 项通过。
- 在使用合成资料的 Android 仓库测试中，103 篇较新的文章不会阻挡后面的 102 条素材，分页和原有文章查询通过。该测试仅证明数据库查询，不证明真实资料同步或 UI 链路。
- 隔离浏览器预览中，文章列表、阅读、编辑首屏、资料信息与候选列表可打开，预览数据不来自用户库。
- 真机空库中：设置分组、人设表单纵向排列、素材与创作空态、编辑正文首屏、键盘、放弃编辑确认和取消后保留文字可见。临时草稿已丢弃，未创建测试记录。
- 修正后真机系统返回从手机 Agent 设置子页回到设置首页。深色状态栏、深色下拉框与中文确认框分别经过真机查看。
- 电脑服务本地资料库只读查询到 550 条未删除记录。手机重新登录并手动同步后，界面显示副本完整、待同步 0、冲突 0；素材与文章列表和文章关联素材候选可读取真实数据。没有逐条核对两端内容。
- 覆盖安装保留了服务和模型配置。真机确认服务人设显示已同步；文章编辑滚动不再被操作栏遮挡，关联素材搜索框样式已修正。未保存文章修改。
- 跟随系统主题在重启后显示浅色并与状态栏匹配；深色到系统的动态切换仍需复验。
