# Android 精简范围

Android 面向随手对话和素材记录，主导航为对话、素材；资料库选择、连接和同步从顶栏进入。

- 本机和远端对话继续使用各自的执行与审批机制。本机工具保留资料查询、读取和经确认的新增／修改；记忆、回顾、删除及恢复管理由服务端或桌面端承担。
- 直接记录、素材编辑保留类型，已有文章保留类型、关联素材、阶段与来源；日记同日追加。旧草稿和待核对请求必须可恢复，不能因界面调整清除。
- 人格与记忆从当前服务获取并按服务缓存。未连接时使用内置助手，服务暂离线使用已验证缓存；资料同步和人格同步分别呈现结果。
- 连接服务、同步、冲突处理和原有资料保留；旧版分享待处理项、文章和标注草稿在完成处理前保留入口。
- 顶栏版本来源于 Android 安装包。版本、备份与数据不得依靠界面文案推断。

先前文档中要求 Android 完整对齐桌面端管理功能的内容不再作为新功能要求。历史文档保留用于追溯，实际可用能力以当前代码和验收结果为准。
