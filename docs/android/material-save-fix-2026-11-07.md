# Android 素材编辑保存修复

## 原因

- `recordRead` 返回展示用 `state`，旧编辑页把完整详情当作更新字段发送，原生 `update` 报 `INVALID_RECORD_FIELD`，记录未进入同步队列。
- 保存时会补正文来源等字段，却复用最后一次编辑草稿的 generation；同一代草稿内容变化可能报 `RECORD_DRAFT_GENERATION_REUSED`。
- 未确认操作恢复后，没有打开详情编辑页；同时导航将它永久视为忙碌，导致用户无法进入重试入口。

## 修改

- 新请求只携带编辑字段；原生兼容旧待确认请求中的 `state`，作为只读字段忽略，保留旧 requestId 和请求内容用于幂等重试。
- 首次提交分配新草稿 generation，提交期间禁用编辑；重试复用已冻结请求。
- 恢复草稿时直接进入编辑页。已持久化的待核对操作允许暂时切换页面，返回后仍可用原请求重试；正在执行的操作仍会阻止离开。
- 明确发生在提交前的草稿校验失败保留可编辑状态，不直接当作记录写入结果未知。
- 使用原正式签名，版本 `0.1.0`，`versionCode=3`。覆盖升级不卸载应用、不清空资料或凭据。
