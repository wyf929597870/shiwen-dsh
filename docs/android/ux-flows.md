# Android 页面与状态设计

日期：2026-11-06。状态：产品流程稿，尚未实施；架构选择见 [架构决策](architecture.md)。

视觉基准为 [已选第二张首页](assets/selected-home.png)。保留拾文 Logo、石墨灰和薄荷绿；默认正文 16sp、列表标题 15–16sp、次要文字 12–13sp、主要触控区至少 48dp。支持字体放大与中英文换行，颜色不能成为区分资料库或状态的唯一依据。

## 1. 导航与首页

底部五个入口：对话、素材、创作、回顾、设置（2026-11-06 用户补充）。服务器节点、模型、同步与其他配置集中在设置。原有插件、自动化任务、Agent 与记忆、外部接入、更多菜单的真实能力必须保留，通过设置内管理入口进入适配手机的完整页面，不能以说明卡片替代功能。服务相关操作明确显示当前节点，离线保留入口和已同步信息，禁止假装执行成功。

首页顶部两行：

```text
个人资料库 · 家里的电脑       [切换] [设置]
电脑未连接 · 3 条待同步
```

中间为当前会话，底部固定输入框；“直接记录”与发送给 Agent 是两种明确操作。点击直接记录打开编辑器，不先发送到模型。无模型配置时仍可直接记录，发送按钮提供配置入口。

执行模式显示“手机 AI · 本机资料”或“电脑端 Agent · 家里的电脑”。切换模式不会自动把整段对话或其他库的资料传过去；以独立会话开始，需要带入某条内容时由用户明确选择。

远端对话另显示连接与任务状态。手机失联时显示“连接中断，执行状态待确认”；重新连接后查询原会话/任务，继续展示正在执行、已完成或等待审批的真实状态。不能显示“任务已中断”并诱导用户再次发送；“停止任务”也要等服务端确认。手机 AI 的本地请求实际中断时，保存已收到内容，由用户决定继续。

来自保存工具的回执示例：

```text
关于记录的想法                         查看
个人资料库 · 自己书写 · 手机创建
✓ 已保存到手机 · 待同步
```

回执仅根据真实工具结果生成。远端 Agent 保存应显示“已保存到服务端”，手机下载完成后再显示“已同步到手机”；不能提前用本地保存回执假装离线安全。

## 2. 首次进入与节点管理

首次可选“使用手机资料库”或“连接服务资料库”。前者创建持久手机资料库，不强迫先登录电脑或配置模型。未配置模型时对话页提供设置入口和直接记录入口；配置后可在没有电脑节点的情况下使用手机 AI。

零节点时顶栏显示“手机资料库 · 仅本机”，不显示“电脑未连接”或同步失败；资料库可自行命名。默认保留全部本机内容，清缓存不删除本机正文、版本或活动。添加不同资料库时，它作为独立库出现；为当前手机库启用同步时保留当前库和记录身份，不重复出现第二份同库。

入口明确区分：

- **连接已有资料库**：按下面流程取得服务上已有库的完整副本；同一 libraryId 已存在则复用。
- **为当前资料库启用同步**：选择已授权的空服务库位置，展示原库完整清单、空间和初始化进度；完成后仍是当前库，之后双向同步。目标已有不同库时不覆盖。
- **更换同步服务**：服务丢失或停用时从完整本地副本恢复；显示恢复切点、其他设备尚未汇合状态及新服务身份。原库可继续使用，不要求先删除旧副本。旧服务返回不自动切回。

添加节点流程：

1. 填写自定义名称和完整 HTTP(S) 根地址。
2. 如果需要局域网权限，此时解释用途并请求；拒绝后保留配置和本地功能。
3. 输入服务访问密码。尚未设置密码的服务提示去服务电脑设置，不能从手机直接成为初始管理员。
4. 登录后核对服务与资料库身份，显示服务端资料库名称、协议兼容状态。
   同时自动获取所选 Agent 的人设、用户偏好与已确认记忆，版本化缓存；未同步成功明确提示，不显示成已载入该助手。新会话绑定快照，已有对话不被后台配置刷新偷偷改写。
5. 展示全库复制范围和预计空间（无法估算时说明未知）；自动同步默认开，不默认选择近期范围。
6. 分批初始化完整正文、元数据、历史版本、关联、活动和库内附件/原件；显示真实进度。已到达内容可先用，完整性校验通过前显示“初次同步未完成”。

顶部切换面板列出：按 libraryId 去重的当前库、其他库和仅本机库；同时显示可达性、待同步数和冲突数。名称由用户命名，远端资料库名称来自服务，两者分别编辑，不能通过手机改昵称修改服务端库名。

节点管理提供改名、修改地址、重新登录、同步设置、缓存管理、停用连接和移除。改地址重新核对身份后才能续用原副本；身份不同应新建连接，不能直接重绑旧队列。

只有一个节点时顶部保持普通标题，点击后仍可管理。多个节点的自动同步不取决于当前选中哪个页面。

## 3. 资料归属标记

| 位置 | 信息密度 |
| --- | --- |
| 首页/列表顶栏 | 当前资料库和节点，列表每行不重复库名 |
| 记录阅读/编辑顶部 | 所属资料库；创建设备、内容来源和同步状态可展开 |
| 跨库搜索结果 | 每条显示库名；默认仍只搜索当前库 |
| 尚未启用同步的手机库 | “仅本机 · 未关联服务”；启用后在同一项显示同步服务 |
| 已删除连接的保留副本 | “本地副本 · 未连接”，保留原库名和身份 |

“手机创建”不能推断为个人原创；“由 AI 工具保存”也不能推断为 AI 内容。混合来源示例显示“用户原话 · AI 整理”，展开可看来源；底层保留实际来源分段。

## 4. 记录、素材与创作

素材列表仅标题、日期和必要的待同步/冲突标志；搜索置顶，类型筛选进入轻量面板。正文独立全屏阅读，返回恢复滚动位置。初始复制或增量更新尚未完成时，未到达的正文显示“同步尚未完成”，不能展示空白正文作为实际内容。完整副本不按日期淘汰历史正文。

直接记录进入编辑页：顶部所属库；标题可选；正文优先；保存时可选日记、想法、自由书写等类型。草稿自动落盘，正式记录有明确保存动作。退出或切换节点时先确认草稿落盘；存储失败不得静默丢弃。

创作列表沿用素材的单栏→正文流程，支持 Markdown 编辑、可读预览、关联当前库素材、状态和发布前检查。手机不堆叠桌面多列面板；检查在独立页/展开区逐项呈现，规则通过不等于已经发布。

从其他 App 分享文本/链接进入拾文时，先显示目标库选择和内容预览。只收到链接时保存链接参考，不能伪称已抓取全文；正文抓取与 AI 总结为独立动作。

不同资料库之间“复制到其他资料库”先保存目标本地副本，再将原条目标为已复制。保留来源去向，目标离线时显示待同步；不会在切换节点时批量归入。

跨库复制有独立预览：显示目标库、正文、关联素材处理，以及“有 2 个附件留在原资料库，不随本次复制”。本轮只复制文本，库内图片/相对附件引用转成非链接来源说明，不保留无效附件按钮、旧库路径或凭据。转换后的正文由用户确认，取消时不产生目标记录，源内容不变。

## 5. 同步详情与状态

当前库同步页展示：连接状态、最后成功同步时间、待上传数、已知待下载数、冲突数、进行中的步骤、立即同步。离线时未知远端变化数量写“连接后检查”，不显示虚假的 0。设备详情显示各已登记端最后确认切点/时间；“协调服务已接收”与“其他端已接收”分开，一次上传不显示“所有设备均已备份”。

同步阶段依次展示“核对上次上传结果 → 获取资料变化 → 上传修改 → 完成检查”。详情可展开按记录查看已成功、冲突、拒绝原因和结果待确认，内部 operationId 不默认占据列表。结果待确认不能显示成“上传失败，请重新创建”，也不能提前显示已同步；后续重试保留原请求。

记录状态和连接状态分开：

| 状态 | 文案与操作 |
| --- | --- |
| 手机资料库中的记录 | 已保存到手机 · 仅本机；可选择复制到服务资料库 |
| 保存到已绑定库，服务不可达 | 已保存到手机 · 待同步；连接设置 |
| 传输中 | 正在同步；继续编辑可用，新修改单独排队 |
| 附件或大载荷尚未验证齐全 | 等待依赖完成；展示缺项/进度，可继续传输，内容仍在手机；不要求重建记录 |
| 上传响应丢失或回执暂未查到 | 正在核对上次上传结果；内容仍保存在手机，不重复新建 |
| 已完成且无未处理项 | 已同步；上次成功时间 |
| 部分成功 | 已同步 8 条，2 条待处理；查看详情 |
| 登录失效 | 需要重新登录；本地记录保留 |
| 权限拒绝 | 需要允许局域网访问；去设置 |
| 资料库身份变化 | 已暂停同步；核对服务 |
| 网络请求失败 | 显示原因、重试时间；立即重试 |
| 内容冲突 | 保留双方版本；处理冲突 |

服务库副本每库设置：自动同步、允许后台同步、传输条件和存储占用；正文与库内原件完整保存，不提供按近期范围淘汰。手动按钮始终可用，但不能绕过身份/登录要求。“全部同步”位于节点管理页；结果按库显示，不用一个总成功遮住失败节点。

关闭自动同步后仍保存记录和队列，不自动上传；关闭后台同步只限制后台，前台自动同步仍可工作。

## 6. 冲突处理

显示记录标题、资料库、修改设备、基线版本以及手机/服务端两个版本。手机屏幕采用页签或上下对照，长文可滚动，不强行左右挤成两窄列。

操作：使用手机版、使用服务端版、手动合并。接受服务端版前提示本地改动会存入冲突历史；使用手机版不是强制覆盖，提交期间再次变化仍需重新比较。删除冲突明确显示“服务端已删除”和本地未同步正文。

服务端已删除时，“使用手机版”改为明确的“恢复并保留手机修改”，说明恢复的是同一条记录；恢复与更新一次提交，只有完整成功回执到达才显示完成。如果服务器版本又变，保留内容并重新比较。接受删除时保留手机内容到冲突历史；原记录无法恢复时提供用户主动选择的“另存新记录”，不自动换 ID。

冲突处理期间保留草稿，退出后可继续；其他记录继续同步。仅当最新提交收到确认后，才移除冲突标志。

## 7. 回顾与 Agent 记忆

回顾保留今日、近 7/14/30 天和自然月。顶部标明“当前资料库”。手机独立库可离线计算完整统计；服务库完整副本可计算截至最后同步切点的完整历史统计，并叠加明确标注的本地待同步活动，不重复计算。只有初次同步/增量数据尚未补齐时提示统计未完成；不一概要求连接电脑才能看完整历史。

跨日离线正式保存保留各自编辑时间；同步当天不把它们集中算成新写作。采用服务端版本而放弃的手机分支保存在冲突历史，不计入权威统计；手机待同步统计会据此更新，不能仍显示那部分已同步。恢复、选择已有版本、复制资料和来源纠正不算新的原创字数。

人格/记忆在设置内按库管理。手机本地用户偏好和资料库共享记忆区分；共享记忆同步默认需要用户开启并有明确范围，候选记忆始终等待确认。不会跨库把“个人偏好”自动注入工作库。

## 8. 缓存、断开与删除

三个不同入口和文案：

- **清理手机缓存**：只清理可重建索引、缩略图与无活动任务引用的临时文件，不删除任何资料库的正文、版本、活动或附件/原件。
- **停用/移除节点连接**：停止调度并撤销或清除本机凭据；默认保留离线副本。服务不可达时不能声称远端凭据已撤销。
- **删除记录**：先形成本地软删除；只有关联服务的库产生同步删除操作，不会通过“清缓存”触发。

清除整个本地副本时，若有未同步内容，要求先同步或导出；不能静默清理。Android 系统卸载通常移除应用私有数据，设置中应说明卸载前处理未同步记录，不宣传卸载后一定可恢复。

## 9. 初始化、恢复与换机

“为当前库启用同步”展示来源库、目标服务、原身份保持、清单/文件数量和空间估计；目标已有不同库时提示另选空服务位置，不提供静默覆盖。阶段显示准备/传输/校验/提交，断开后保留任务可继续；提交响应未知时核对原任务，不另建一份资料库。另一台设备正在初始化/恢复同一目标时显示“此服务正在处理另一个初始化任务”，可查看有权查看的任务或等待；不提供强制覆盖。预留失效先重新核对目标再恢复，目标已变化则停在确认差异页，不自动提交旧快照。

“更换同步服务”区分主动迁移与旧服务不可达。先显示此副本完整到哪个时间切点、待同步数及缺文件；不完整来源进入“救援暂存，尚缺 N 项”：仅只读查看/导出已找回内容，可选择其他已授权同库来源补齐，不提供启用可写服务、Agent 写入或跳过缺项按钮。取消只停止恢复并保留候选和原库；清理候选是独立操作。恢复后显示“新服务已恢复，其他设备待汇合”，列出各设备最后确认时间。另一端携带较新历史回来时展示差异和冲突，不显示“以新服务器为准，清空本地”。用户已确认的新服务不会因旧服务重新出现而自动切回。

设置增加“备份与迁移”：Markdown 导出/导入、完整备份、恢复原库、导入为新库。完整包覆盖数据、历史、草稿和未同步分支，可选会话/记忆与加密，明确不包含登录凭据/模型 Key。导出选择用户保管位置，提供成功校验与最近备份信息；不自动上传云。恢复前展示内容、版本兼容与缺项，先暂存验证；错误口令/损坏包不会修改当前库。新设备登录和模型配置需重新设置。恢复原库后，即使连接的仍是原服务，也显示“正在核对原设备的同步结果”；所有者授权后核对历史版本、活动和未知上传。界面区分原创建设备与本次提交设备，不把恢复历史计为今日新增；旧手机重新上线按相同身份去重，存在分支时展示冲突。

同步页分别展示“本机保存”“服务确认”“本端完整接收”“其他设备最后确认”；完整接收仍可能有本地待上传/冲突，不能用一个绿点代替这些状态。普通列表继续简洁，这些详情只在同步/设备页展开。

长文传输显示“准备传输 → 已传大小/总大小 → 校验 → 提交”，正文仍可读、继续编辑作为后继保存。网络/体积限额改变时保留原请求并续传，不提示用户删正文/来源来适应批次限制；服务能力不足提示升级并保留本地内容。文件传完不等于记录已同步，只有业务确认后才显示成功。

## 10. 设计验收

- 不连接任何服务也能写一条记录，强停并重开后可找到。
- 服务库初次全量同步完成后，断开电脑仍能查询跨月历史、查看版本与附件、编辑和回顾；清缓存不会删除这些资料。初始化未完成不能显示“完整副本”。
- 一眼可辨当前库、执行 AI 的位置，以及记录是否只在手机。
- 单库列表不重复堆积来源标签，多库结果不省略所属库。
- 输入法弹出时输入与保存操作可达；系统返回先收键盘，再返回页面；不丢草稿。
- 标准字号和大字号下主要按钮可点，无横向溢出；正文代码块/表格只在自己的区域横向滚动。
- 深浅主题的次要文字、错误、冲突和触控状态清晰；英文长名称不遮挡切换按钮。
- 截图校对采用同尺寸的选定图与实际页面并排比较；概念图中的错误说明不能机械照搬。
- 模拟上传响应丢失时显示对账过程，继续编辑的新内容仍待同步；未知结果不诱导重新建记录。
- 服务端已删除的冲突可一次恢复并保存手机正文；跨库复制预览和最终文本一致，无失效附件入口。
- 手机失联后远端完成的会话可在重连时找回；状态和按钮不诱导重复发起任务。

- 手机先建库后启用同步不出现第二个同库；setup 提交回执丢失能恢复原任务。
