# PC 语义搜索验收记录

日期：2026-11-17。资料均为隔离临时库中的虚构内容；本记录区分真实模型、模拟测试和未验证事项，不将模拟结果视为实际模型或设备验收。

| 方案验收项 | 当前证据及范围 | 尚未覆盖 |
| --- | --- | --- |
| 精确搜索兼容 | 隔离 Web 实测素材关键词、读书章节；索引测试覆盖无模型精确查询和空关联范围。 | 原有全部查询、类型与阶段组合的完整浏览器回归。 |
| 真实语义能力 | 隔离 Web 实测自由书写无原词语义查询，隔离真实服务与 ONNX 测试通过。 | 独立标注且获用户认可的真实或脱敏样本；不能据虚构样本宣布普遍准确率。 |
| 四个入口 | 隔离 Chrome 中实测素材、文章、读书和写作素材栏真实模型查询；实测素材类型、读书本书/全部书、章节、类型、日期、写作本篇及书籍筛选；写作栏选区引用并关联、文章保存。实际 Electron 调试包使用隔离 profile、打包服务与真实模型，已实测四入口查询，读书打开正确感想上下文。 | 全部筛选组合和桌面实际进程中的写作关联、引用及保存。 |
| 原文可核对 | 隔离 Web 实测素材和读书感想/章节定位；旧版双摘录命中第二条及其页码，写作栏引用第二条并保留章节、页码。两窗口实测展开后原文被修改时，插入前重新校验并阻止旧引用。 | 其他编辑后重定位的真实浏览器回归。 |
| 内容一致性 | `node --test --test-isolation=none tests/pc-search-index.test.mjs`：临时 SQLite 经真实写入路径覆盖日记追加、Wiki 导入、同步 push、删除恢复；旧结果排除、版本变化、重启及异步过期结果由模拟向量验证。 | 这些写入路径与真实 ONNX 结合的完整端到端回归；长时间后台队列恢复、更多同步冲突场景。 |
| 两端共用 | 同一服务架构和并发模型任务有自动化覆盖；Web 显示服务位置，同服务第二标签显示相同模型与索引状态。实际 Electron 调试包与 Chrome 连接同一服务，相同读书语义查询均返回同一条感想。 | 远端服务访问及内存中仅一模型实例的系统级核实。 |
| 错误与竞态 | 模型测试模拟首次离线、下载流中断、校验失败；真实 Node 工作线程异常退出模拟、重试；模拟后台取消时共享 worker 的前后台请求均拒绝、状态失败可重试，损坏索引可保留原文搜索并重建。UI 自动测试覆盖 IME 组词、迟到响应及旧锚点。真实 Chrome 桌面双栏测试 28 条结果的滚动位置、查询与详情切换保留。服务拒绝非回环连接后重启，已验证离线真实语义查询。 | 实际磁盘写满、下载时真实网络中断、真实中文输入法及窄屏返回后的滚动恢复。 |
| 性能 | 真实 ONNX、临时 SQLite 资料库与服务层一万片段：i7-1260P / 32 GB / Linux、Node 24.16.0、CPU 推理两线程。首轮 p95 5.18 秒；批量快照和有界向量缓存后，模型加载 864.77 ms、建库 57.05 秒、首查 471.39 ms、30 次热查询 p50 148.17 ms / p95 198.24 ms / 最大 215.93 ms，进程峰值 RSS 776,364,032 字节，达到该机器上的 500 ms 工程目标。可用 `node scripts/benchmark-pc-search.mjs <已校验模型父目录>` 复现。 | 不含 HTTP 和桌面渲染开销，OS 文件缓存未冷清；其他硬件尚未测试。 |
| 正式推理一致性 | 隔离评测中 100 个向量的 ONNX/PyTorch 最低余弦 0.9999998846；10 条查询 top-5 完全一致。 | 更多独立样本和其他平台的结果。 |
| 平台与回归 | Chrome / Web 与 Electron 调试包的上述路径及相关自动测试已运行。正式 Linux 0.1.26 deb 解包后，包内 Node 与 ONNX worker 使用预先校验的模型离线运行，返回 512 维向量。 | 正式 deb 的 GUI 安装、Electron 的完整编辑与引用回归、Windows 实机、Android 设备共用组件回归。 |
